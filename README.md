# Chexpert-Base
CS-452 project 

download dataset from the following link:
https://stanfordmlgroup.github.io/competitions/chexpert/

The dataset is taken from the CheXpert collection and consists of images with various chest afflictions. The goal of the project is to recognize and identify what kind of disease the patient is suffering from. The base model is a densenet and the technologies being used are Python and Tensorflow.
